## Detailed description

```
Notely is a fast, private notepad that lives right in Chrome. Take notes in the toolbar popup, keep them open in the side panel while you browse, or write in a full tab. Every note stays in sync, and everything is stored locally on your device.

★ WRITE BEAUTIFUL NOTES
• Rich-text editor with headings, bold, italic, underline, highlights, quotes, code blocks, links and emoji
• Markdown shortcuts as you type: "# " for a heading, "- " for a list, "[ ] " for a checklist, "> " for a quote, ``` for code
• To-do lists and checklists with nesting (Tab / Shift+Tab)
• Reliable undo and redo, and clean copy-paste from any website
• Light and dark themes, six accent colors, Sans / Serif / Mono fonts

★ NOTES IN THE SIDE PANEL
• Keep your notepad open next to any website while you research, shop, study or work
• Open it instantly with Alt+Shift+O, or start a quick note with Alt+Shift+Q

★ WEB CLIPPER
• Right-click to save selected text, a whole page or a link to Notely
• Press Alt+Shift+S to clip the text you selected
• Every clip keeps its source link, so you can always find where it came from
• Optional "Save to Notely" button that appears when you select text (off by default, can be hidden per site)

★ ORGANIZE AND FIND ANYTHING
• Search all your notes instantly
• Notebooks, tags, pinning and archive
• Command palette (Ctrl/Cmd+K) for every note and action
• Trash with undo, so nothing is ever deleted by accident

★ VERSION HISTORY
• Automatic snapshots while you write
• Preview and restore any earlier version of a note

★ EXPORT AND BACKUP
• Export notes as Markdown, HTML or plain text, or copy as Markdown
• Full JSON backup and restore

★ PRIVATE BY DESIGN
• 100% local: notes are stored on your device with Chrome storage
• No account, no sign-up, no servers, no ads, no tracking
• No access to websites unless you turn on the optional selection button
• Open source, so you can read every line of code

Great for: quick notes, to-do lists, meeting notes, research, study notes, saving quotes and links, drafting emails and journaling.

★ OPEN SOURCE
Source code, issues and feature requests:
https://github.com/Toolvanta/notely

★ SPONSORED BY TOOLENHANCER
Notely is proudly sponsored by ToolEnhancer:
http://toolenhancer.com/

Made by Shoaib Arif - https://shoaibarif.vercel.app/
```

> Keep it honest: the Web Store rejects listings with keyword stuffing or claims the extension doesn't deliver. Every line above describes a real feature.
